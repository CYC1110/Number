# Candidate figure dependency map

Evidence was read from the `260925B` manuscript figure captions, its appendix figure captions, the methods notes, the 2D representation/trajectory READMEs and the source scripts listed below. This identifies a candidate coverage set, not a user-confirmed final manuscript. Source artwork is manually assembled; the commands here render new method figures and do not reproduce its pixels, panels or original cohort values.

The common chain is `data/* -> training.py -> checkpoints/<state>/<run>/epoch_NNN.pth -> pipeline.py -> results/<state>/<run>/epoch_NNN -> figures.py`. Every condition uses its full configured cohort: the four original conditions use 20 runs and all other states use five (see [COHORTS.md](COHORTS.md)). Run `iclr-repro analyze STATE --run RUN --epoch EPOCH --execute` for every required state/run. F2 also requires `--single-unit`. S5 requires all configured milestones. The methods document defines each estimator.

The F2 human developmental panel is external evidence: its raw data/artwork and reuse permissions were not established and are not invented. F4's ResNet-50 overlay can be inspected through S5 and its separate configured analysis; the new F4 layout is the AlexNet state comparison. F5's manually composed example-photo/decoder insets are represented through the measured outputs/S6 inputs, not historical bitmaps. S7 can be rotated offline; capturing an image requires a deliberate viewpoint choice and does not constitute a replay of original manuscript screenshots. These are explicit layout/panel differences, not silently dropped analyses.

The current reference omits auxiliary adaptive-rank geometry, original continuation/Random-trained conditions, exploratory 105k synthetic studies and original frozen task registries. The reviewed original source contained different SimCLR/DINO cohort sizes and alternative P6/adaptive-rank analyses; those are not included in the condition-specific P7 reference aggregation. Primary requested quantitative methods are implemented and accessible in metrics even when their original visual inset is not recreated.
