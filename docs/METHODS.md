# Method definitions and review boundaries

The intended use is to inspect whether the analyses are well defined. Condition-level replication uses n=20 for Untrained, Pretrained, Label-shuffled and DVD, and n=5 for the other configured states; see [COHORTS.md](COHORTS.md). The code does not certify the validity of a scientific conclusion or claim to reproduce published values.

## Preserved numerical definitions

The source manifest records the relative source file, SHA-256 and extracted definitions for pure numerical primitives. Count-weighted level means, centering over N/P levels, SVD, principal angles, exact cell-by-set balanced three-fold/split-half assignment, Gaussian Bhattacharyya coefficient and two-way ANOVA are preserved from the reviewed source. P7 reimplements the inspected `conditioned7` definition: integer W/N is assigned with `(1,3,5,7,9,11)/12`, sample-count weighted P level means are centered by the unweighted mean of seven level means, then SVD is taken. N1/P2 is fixed.

For N, cell centroids are averaged using the observed sample counts at each N level. PCA is computed on the centered level effects, not on raw single-image variance. Cumulative EV comes from squared singular values of those level effects. Principal angle is the first angle between N1 and the two-dimensional P subspace; the N-PC1/P-PC1 display angle is a different quantity and is not substituted.

## Geometry and overlap

The NP grid has N=1–30 and W=0–N, totaling 495 cells. P is reconstructed from integer W and N. Each cell has all three regimes. The split uses stable per-cell/per-regime seeds. It selects the largest common multiple of three repeat counts, with at least two images per regime per fold; leftover rows are explicitly excluded from held-out measurements. Training and held-out images do not overlap. The full-data descriptive angle includes all nonblank images.

BC uses the span of N1 and P2 fitted to the other two folds. Rank-deficient spans are undefined. Held-out cell distributions are fitted in that three-dimensional span with Ledoit–Wolf covariance. For each pair, BC is `exp(-mean_term - covariance_term)` with the Gaussian determinant factor. Pair coefficients are averaged, not distances followed by exponentiation. Every one of 122,265 unordered pairs has equal weight. Fold means then have equal weight. Positive definiteness is checked. Undefined values remain null in JSON; configured-cohort plots reject an undefined canonical value rather than omitting a network. There is no ridge repair or replacement with valid-pair diagnostics.

Common nonzero scalar activation normalization does not change principal angle or BC, so these reference endpoints use raw activations. Distances/volumes/normalized moment features from exploratory analyses are outside this package's scope. Two-dimensional ellipses display one standard deviation, not confidence intervals. The offline 3D viewer uses the same held-out means/covariances as overlap.

## Readouts, leakage and ablation

Readouts are affine softmax classifiers with no hidden layer. Fold A trains, B selects the epoch using cross-entropy, C is held out. The full-batch Adam defaults in configuration are new transparent reference choices, not asserted historical optimizer settings. No preprocessing is fitted to test features. Exact NP classification uses only observed `(N class, P class)` combinations; N and P class errors are ordinal, whereas NP class IDs are nominal.

Cross-quantity ablation is `X - (X U) U^T` with orthonormal U. N readout removes P rank 2, P readout removes N rank 1. The origin is raw zero. The decoder is frozen and damage is ablated MAE minus baseline MAE in N steps/P-class steps. The full-data basis is the primary descriptive definition preserved from the reviewed P7 code. Because its supervised conditioned PCA sees test labels/stimuli, the ablation experiment is not an inductive held-out estimate of basis learning. `--basis-scope train` fits the ablation directions on A only; it changes that estimator intentionally and must be reported separately. Geometry itself remains descriptive full-data PA plus held-out BC in both modes.

Comparison uses difference representations, mirrored orientations and disjoint source-image folds. NP comparisons restrict N gaps to at most two and P-class gaps to one. Incongruence means the other quantity points in the opposite direction, with ties excluded. Reference pair matching uses sorted-index, equal-count matching within each pair and averages pair accuracies equally. It is not a reconstruction of the original frozen pair registry and can have different nuisance balance. Matching, count, solver iteration count and cap are recorded; solver convergence warnings must be reviewed rather than interpreted as successful optimization.

Cross-context transfer is bidirectional between the lower/upper halves of the other quantity's levels, restricting evaluation to common target-label support. A/validation B are in the source context; C is in the destination context. This is an explicit review example, not the original hand-selected context registry. Its support restriction may change chance levels and must accompany interpretation.

Single-color ANOVA requires a complete balanced N × regime factorial design. Nonblank NP stimuli are not substituted for this dataset. The original uncorrected alpha .01 N significant / regime and interaction nonsignificant criterion is retained. Selection is fitted on A, then equal-size selective/nonselective samples are evaluated on independent C images over five draws, capped at 256 units. This differs from the historical independent stimulus-cache selection. A zero selective count is reported, not replaced by invented units.

## Training reference vs historical recipes

The reference trainer demonstrates where the checkpoints come from; it is not the scientific basis for asserting a matched historical visual experience. AlexNet convolution initialization uses the inspected He-normal formula. Supervised and partial-label controls use a fixed permutation and report the retained fraction; accidental label matches in the permuted subset must not be described as intentional correct labels. The reference optimizer is SGD .01/momentum .9/weight decay .0005 with a cosine schedule. SimCLR uses the inspected NT-Xent definition and an fc7 encoder; its compact head and AdamW recipe differ from historical LARS/DALI choices. RotNet uses four rotations. DINO implements the cross-view teacher loss, EMA and center update with ten student crops/two teacher crops; the simplified head and augmentation pipeline differ from the original weight-normalized head, crop-specific blur/solarization and 90-of-100 schedule. These differences are disclosed rather than disguised as reproducibility.

DVD takes a supplied stored degraded diet; its developmental transform is not reimplemented here. Statistical requires official local WMM images. Shader generation needs actual local programs/templates and optional hardware EGL. No weights or assets are automatically fetched. Noise/Grating and NP placement primitives retain their inspected mathematical definitions. The new generation frontends omit exploratory diagnostic plots and record only images, hashes, parameters and placement success.

The inspected single-color legacy generator could finish placement attempts without raising when the target count was not achieved, and its set-2 interpoint-distance condition is undefined for a one-dot image. The new frontend explicitly fails incomplete placements and exempts only N=1 from that distance constraint. Implicit caches are disabled. These changes are documented safeguards, not evidence that historical cached stimuli or reported results were invalid; those image contents were not audited or regenerated. They also mean the frontend does not claim pixel-identical replay of the historical cache.

## Statistics and figure interpretation

Networks are the replication units, not dot images, Gaussian pairs, folds or decoder draws. The original Untrained/Pretrained paired test matches the same 20 run IDs (and their common initialization seeds), and computes a two-sided t-test of Pretrained minus Untrained (df=19). The reference pairs explicit seed-to-value mappings, independently of row order. Any unequal-cohort comparison uses only the intersection of initialization seeds, reports both complete cohort sizes, matched pair count/df, and unmatched seeds, and labels its effect as a matched-subset difference. It never pairs by array position or truncates to the shorter array. Shared seed identity permits an initialization comparison, but does not establish identical optimization or image exposure; no historical unequal-cohort inferential protocol was established. Bars use sample SD divided by sqrt(actual configured n); state geometry maps use sample SD. Correlations use matched condition means, not pooled per-image data, with Pearson r and two-sided p. OLS bands are 95% confidence intervals for the fitted mean, not prediction intervals. Derived states can share initialization/data and therefore violate strong independence assumptions; the reported correlation is descriptive. Multiple pairwise/correlation tests are not silently corrected or relabeled as confirmatory.

No configured-cohort mean is computed from an incomplete or nonfinite cohort. All 20 or five records must be present with matching state/run/epoch, configured initialization seed and cohort count. Trajectories use the same condition-specific cohort at every milestone. No missing point is interpolated. The 90% EV line is a diagnostic, not a condition-selection rule. Scientific interpretations still require checking dataset nuisance balance, optimizer convergence, basis leakage, model training quality, the selection of context/pair tasks and comparisons to the actual manuscript/source results.
