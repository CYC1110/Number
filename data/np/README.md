# NP evaluation stimuli

`iclr-repro generate-np --execute` creates `set_<s>/N_<n>/w_<w>_b_<b>/<index>.png` and `metadata.json`. Configuration is in `configs/np_dataset.json`. N=0 blanks are generated but excluded from analysis: 18,600 generated / 18,000 evaluated / 495 nonblank cells. Never populate this directory during a lightweight test.
