# Analysis outputs

Per-network outputs: `<state>/<run>/epoch_<NNN>/`. `metrics.json` records estimator definitions and project-relative provenance. Bases, held-out Gaussians, readout predictions and affine weights support inspection. `single_unit/` contains separate ANOVA/tuning/SVM outputs. `fid.json` contains local FID results. Contents are ignored by Git; no actual research outputs are included.
